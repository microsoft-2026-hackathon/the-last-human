쓰기 주체는 서버 하나뿐이다

Actions는 이벤트를 전달하고 독립적으로 다시 계산해 대조한다. 모델은 질문을 쓰고 근거를 대조할 뿐, GitHub 상태를 바꾸거나 머지를 승인하지 않는다.

봇이 자기를 통과시키지 않는다
Actions가 대상 PR의 스냅샷과 위험도를 독립적으로 다시 계산해 서버의 영수증과 대조한다. 어긋나면 게이트가 열리지 않는다.
⑤ · lasthuman-app.yml — 5단계
비밀은 서버에만 있다
App 개인키·client secret·모델 자격은 Actions로 넘기지 않는다. Actions는 단기 OIDC만 들고 저장소에 묶인 신원을 증명한다.
② · 사전 공유 장기 시크릿 없음
모델은 판정하지 않는다
질문 생성과 근거 대조를 돕는다. 위험 점수는 순수 함수라 같은 입력이면 같은 출력이 나오고, 모델은 GitHub 상태를 바꾸지 못한다.
