## 1. 한 줄 논지

> agent는 이미 SDLC 전 단계에 들어와 있고 모든 단계가 기록됩니다. **merge의 신뢰만 기록이 없습니다.** The Last Human이 그 한 층을 만듭니다.

## 3. 챌린지 정합

Hack for Agentic Coding은 GitHub Copilot으로 SDLC와 개발 워크플로를 혁신하는 프로젝트를 찾습니다. 정합 지점은 다음과 같으며, **근거가 있는 것만** 주장합니다.

| 챌린지 요건 | 우리의 대응 | 근거 |
| --- | --- | --- |
| GitHub Copilot 활용 | 데모 PR이 실제로 Copilot이 쓴 것입니다 | `docs/runbooks/first-demo-macos.md`의 `Co-authored-by: Copilot` |
| SDLC 전반의 혁신 | 02가 7단계를 놓고 merge 지점의 공백을 지목합니다 | 슬라이드 02 |
| 마찰·병목 감소 | 병목은 코드 생성이 아니라 merge의 신뢰입니다 — 55.8시간 vs 16.0시간 | 슬라이드 04 |
| 에이전틱 기능을 실제 영향력으로 | 신뢰 층이 없으면 rubber-stamp 아니면 금지이고, 어느 쪽이든 생산성은 실현되지 않습니다 | 슬라이드 05 |

### gate 이력 — 07의 근거

**이력은 이 저장소가 아니라 개발 저장소에 있습니다.** `microsoft-2026-hackathon/the-last-human`은 2026-09-15에 만들어진 이관 대상이라 PR이 7건뿐입니다. 실제 이력은 `hunhoon21/the-last-human`에 당시 이름인 `comprehension-gate`로 남아 있습니다. 근거는 [`docs/migration/import.json`](../migration/import.json)입니다.

| 값 | 수 |
| --- | --- |
| gate가 발동한 PR | **26** (전체 29건 중) |
| 설명 대기로 한 번 이상 멈춘 PR | **15** |
| 통과 기록으로 끝난 PR | **14** |
| 멈췄다가 통과한 PR | **3** (#22 · #12 · #5) |
| 대기 상태로 merge된 PR | **12** |

**"26건을 다 막아 세웠다"고 말하지 않습니다.** 12건은 gate가 대기 중인 채로 merge됐고, required check를 계속 걸어 두지 않았기 때문입니다. 물으면 그대로 답합니다.

| "gate도 AI한테 물어보면 되지 않습니까?" | 코드와 질문을 함께 주면 상당수 맞힙니다 — 사실입니다. 다만 **어떤 코드를 줄지 먼저 알아야** 합니다. 질문은 특정 hunk를 가리키고 근거로 코드 위치를 요구합니다. 목표는 부정행위 차단이 아니라 **승인 전 최소 한 번은 코드를 보게 만드는 것**이고, 지금은 그 한 번조차 없습니다. |
| "모든 PR을 막으면 개발이 마비되지 않습니까?" | 전수 적용하지 않습니다. 임계값 미달은 `Not required`로 지나갑니다. 데모 안에서 문서 PR이 그대로 merge되는 장면으로 증명됩니다. |
| "모델이 죽으면 어떻게 됩니까?" | 사람을 막지 않습니다. **실패 방향에 일관성이 있습니다** — 사람이 답을 빠뜨리면 막고, 인프라가 죽으면 통과시킵니다. 미통과는 failure가 아니라 pending입니다. |
| "보안은 어떻습니까?" | App private key · client secret · 모델 자격은 **서버에만** 둡니다. 경계를 넘는 것은 단기 OIDC와 metadata뿐입니다. 다만 **"비밀이 전혀 없다"고는 말하지 않습니다** — Actions도 단기 GitHub 자격은 갖습니다. |
| "서버 하나로 여러 저장소가 됩니까?" | 지금은 **서버 1대 = 저장소 1개** 바인딩입니다. 패키징에서 정리 중이고 숨기지 않습니다. |
| "사내망에도 둘 수 있습니까?" | webhook 수신자가 아니라 **relay** 구조라 가능합니다. self-hosted runner와 사내 접속 경로가 필요하고, 대가는 runner 기동 지연 20–40초입니다. |
| "Copilot과 경쟁하는 것입니까?" | 아닙니다. **Copilot이 연 PR을 조직이 받아들일 수 있게 만드는 층**입니다. 신뢰 층이 없으면 조직은 rubber-stamp하거나 금지하는데, 어느 쪽이든 Copilot의 생산성은 실현되지 않습니다. |
| "Global 진출은 가능합니까?" | GitHub PR 흐름 위에서만 동작해 지역·언어 종속이 없습니다. 정책은 `.lasthuman.yml` 한 파일이고, 모델은 조직이 고른 Azure 리전을 씁니다. 다만 구조 분석은 현재 **Python 중심**입니다. |
| "기간 내에 얼마나 만들었습니까?" | commit 109건, PR 36건, test 519건, 동작 중인 workflow 4개입니다. 그리고 **그 PR들이 이 gate를 통과했습니다.** |
| "개인 평가로 쓰이지 않겠습니까?" | 개인 점수·순위·팀장 조회는 요청받아도 만들지 않습니다. 대시보드는 이름이 아니라 **수**를 셉니다. 만드는 순간 다른 제품이 됩니다. |
